# Testimonials Component

This is a simple Testimonials Component project made using HTML and CSS.

## Features

* 2x2 testimonial cards layout
* Responsive design
* Testimonial slider section
* Flexbox and CSS Grid
* Modern UI design

## Technologies Used

* HTML
* CSS

## How to Run

1. Download the project
2. Open `index.html` in your browser
